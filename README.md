# DriveNest

Car rental platform: customers search and book cars by date range, staff handle
pickup/return, owners manage the fleet, prices and reports.

Portfolio project. Work in progress.

## Stack

Java 21 + Spring Boot 3, PostgreSQL (Supabase) with Flyway, Supabase Auth (JWT),
React + Vite, Docker Compose, GitHub Actions.

## Structure

```
backend/      Spring Boot API
frontend/     React + Vite app
monitoring/   Prometheus / Grafana configs (v2)
.github/      CI workflows
```

## Getting started

1. Copy `.env.example` to `.env` and fill in the values.
2. Setup and run instructions will be added as the project grows.
